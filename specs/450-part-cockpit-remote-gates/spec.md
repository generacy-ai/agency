## Context

P4 integration / dogfood (human-run): drive a real epic end-to-end with `--gates=ui`, answering everything from the generacy.ai inbox.

## Scope

- Run `/cockpit:auto --gates=ui` on a real (scratch or live) epic and exercise every reachable gate type from the inbox: clarification batch (including a free-text "Make changes" round), review verdicts (approve and request-changes), phase-queue confirm, at least one escalation, and a supersession case (answer a gate after its state moved on).
- Verify: session keeps dispatching while gates are open; answers arrive and apply; acks/outcomes and delivery states render correctly in the inbox; GitHub audit artifacts (clarification markers, advance comments, labels) carry the UI actor attribution; offline-cluster answer delivery on reconnect.
- Document rough edges and file them as follow-up issues on the epic; update the cockpit walkthrough/docs where operator-facing behavior changed.
