```markdown
# /agency-spec-kit:specify

Create a new feature specification from a backlog ticket.

## Usage

\`\`\`
/agency-spec-kit:specify [ticket]
\`\`\`

## Workflow

1. **Get ticket details** (if provided)
   - Call `spec_kit.get_ticket` with the ticket reference
   - Extract title and description

2. **Create feature branch and directory**
   - Call `spec_kit.create_feature` with ticket title/description
   - Creates branch: `{number}-{slug}`
   - Creates directory: `specs/{number}-{slug}/`

3. **Initialize spec.md**
   - Call `spec_kit.copy_template` for spec template
   - Pre-populate with ticket information

4. **Link to ticket** (optional)
   - Update ticket with branch reference

## Example

\`\`\`
> /agency-spec-kit:specify #42

Creating feature from ticket #42...
- Fetched ticket: "Add user authentication"
- Created branch: 042-user-authentication
- Initialized spec at: specs/042-user-authentication/spec.md

Ready for specification! Edit spec.md to refine requirements.
\`\`\`
```
