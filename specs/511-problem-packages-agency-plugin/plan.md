## Design

### New step 5 text (exact contract — see contracts/plan-step5.md)

Step 5 becomes a "Write the tech stack summary" instruction:

- Target: `specs/<feature>/stack.md`
- First line (exact): `Generated by /plan — do not hand-edit.`
- Content: language, framework, dependencies, notable technical decisions
- Re-run semantics: **fully overwrite** — never append; history lives in git (Q2)
- Single prohibition sentence naming the forbidden files literally (Q1):
  the plan phase must NEVER modify repo-root agent-context files (`CLAUDE.md`,
  `AGENTS.md`, `GEMINI.md`, `.github/copilot-instructions.md`).

The wording is frozen in `contracts/plan-step5.md`; the pin test asserts it verbatim.

### Pin test assertions (Q1 + Q3)

For **both** copies (canonical + mirror, read via relative paths from the test file):

1. **Absence**: `update_agent` appears nowhere (case-insensitive).
2. **Scoped absence**: matches of `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`,
   `copilot-instructions.md`, and `/agent[\s-]context/i` (regex catches the hyphenated
   variant) occur **only** within the single NEVER-modify prohibition sentence.
3. **Presence**: the `specs/<feature>/stack.md` instruction, the exact header line
   `Generated by /plan — do not hand-edit.`, the overwrite-not-append instruction, and
   the prohibition sentence are all present.
4. **Identity**: the two copies are byte-identical (string equality of raw file contents).

Failure of any assertion on reintroduction of old step 5, deletion of the stack.md
instruction, or copy drift satisfies SC-002.

### Changeset (deviation from FR-006 as literally written)

FR-006 asks for a changeset covering "both spec-kit packages", but
`claude-plugin-agency-spec-kit` has no `package.json` and is not a versionable
workspace package. The changeset therefore names only
`@generacy-ai/agency-plugin-spec-kit` with a **minor** bump (Q4) and mentions in its
body that the deprecated mirror copy was updated in lockstep. This satisfies the
intent (changelog visibility for the behavior change) within what changesets can express.

## Constitution Check

`.specify/memory/constitution.md` does not exist in this repo — no constitution gate to
evaluate. Applicable repo-level governance from `CLAUDE.md`: playbook pin tests assert
exact contract strings and must be re-pinned (never weakened) when contracts change.
The new pin test follows that philosophy.

## Risks

- **Em-dash fidelity**: the required header uses an em dash (`—`). The pin test must
  assert the exact bytes; authoring tools that normalize dashes would break identity.
  Mitigated by the pin test itself.
- **Grep-based SC-001**: `grep -i "claude.md"` will match the prohibition sentence by
  design; SC-001 was adjusted by Q1 to permit exactly that.
