# Feature Specification: Fix build dependency ordering for agency-plugin-git

**Branch**: `131-fix-build-dependency-ordering` | **Date**: 2026-01-24 | **Status**: Draft

## Summary

## Summary
The `agency-plugin-git` package fails to build because it depends on `@generacy-ai/agency` which must be built first. The turbo build configuration needs to be updated to ensure correct dependency ordering.

## Problem
When running `pnpm build` or `turbo build`, the git plugin attempts to compile before the core agency package has generated its dist files, causing TypeScript compilation errors.

## Expected Behavior
Build should succeed with all packages compiling in the correct dependency order:
1. `@generacy-ai/agency` (core) builds first
2. All plugins build after core is complete

## Suggested Fix
Update `turbo.json` to explicitly define the build dependency:
```json
{
  "pipeline": {
    "build": {
      "dependsOn": ["^build"]
    }
  }
}
```

Or ensure the package.json dependencies correctly reference the workspace package.

## Impact
- **Blocking**: Cannot use git plugin tools until fixed
- **Scope**: Build configuration only, no runtime changes
