# Quickstart: MCP Server Foundation

## Installation

```bash
# Install the core package
pnpm add @generacy-ai/agency
```

## Basic Usage

### 1. Create Configuration

Create `.agency/config.json` in your project root:

```json
{
  "name": "my-project-agency",
  "plugins": [],
  "modes": {
    "default": ["*"]
  }
}
```

Or add to `package.json`:

```json
{
  "agency": {
    "name": "my-project-agency",
    "plugins": [],
    "modes": {
      "default": ["*"]
    }
  }
}
```

### 2. Start the Server

```typescript
import { AgencyServer } from '@generacy-ai/agency';

const server = new AgencyServer();

// Start accepting connections
await server.start();

// Server is now running on stdio
```

### 3. Register Tools

```typescript
import { AgencyServer, AgencyTool } from '@generacy-ai/agency';

const myTool: AgencyTool = {
  name: 'myns.hello',
  description: 'Say hello',
  namespace: 'myns',
  outputPattern: 'terse',
  inputSchema: {
    type: 'object',
    properties: {
      name: { type: 'string', description: 'Name to greet' }
    },
    required: ['name']
  },
  async execute(params) {
    const { name } = params as { name: string };
    return {
      content: [{ type: 'text', text: `Hello, ${name}!` }]
    };
  }
};

const server = new AgencyServer();
server.registerTool(myTool);
await server.start();
```

### 4. Create a Plugin

```typescript
import type { AgencyPlugin, AgencyTool } from '@generacy-ai/agency';

const greetTool: AgencyTool = {
  name: 'greet.hello',
  description: 'Greet someone',
  namespace: 'greet',
  outputPattern: 'terse',
  inputSchema: {
    type: 'object',
    properties: {
      name: { type: 'string' }
    },
    required: ['name']
  },
  async execute(params) {
    const { name } = params as { name: string };
    return {
      content: [{ type: 'text', text: `Hello, ${name}!` }]
    };
  }
};

export const greetPlugin: AgencyPlugin = {
  name: 'greet-plugin',
  version: '1.0.0',
  tools: [greetTool],
  async initialize() {
    console.log('Greet plugin initialized');
  },
  async shutdown() {
    console.log('Greet plugin shutdown');
  }
};
```

Load the plugin:

```typescript
import { AgencyServer } from '@generacy-ai/agency';
import { greetPlugin } from './greet-plugin';

const server = new AgencyServer();
await server.loadPlugin(greetPlugin);
await server.start();
```

### 5. Use Modes

Configure modes in `.agency/config.json`:

```json
{
  "name": "my-project-agency",
  "plugins": ["./greet-plugin"],
  "modes": {
    "default": ["greet.*"],
    "minimal": ["greet.hello"]
  },
  "defaultMode": "default"
}
```

Switch modes at runtime:

```typescript
const server = new AgencyServer();
await server.start();

// Later, switch to minimal mode
server.setMode('minimal');

// Check current mode
console.log(server.getMode()); // "minimal"
```

## Available Commands

### Server Lifecycle

| Method | Description |
|--------|-------------|
| `server.start()` | Start the MCP server |
| `server.stop()` | Gracefully stop the server |

### Tool Management

| Method | Description |
|--------|-------------|
| `server.registerTool(tool)` | Register a single tool |
| `server.unregisterTool(name)` | Remove a tool by name |

### Plugin Management

| Method | Description |
|--------|-------------|
| `server.loadPlugin(plugin)` | Load a plugin instance |
| `server.unloadPlugin(name)` | Unload a plugin by name |

### Mode Management

| Method | Description |
|--------|-------------|
| `server.setMode(mode)` | Switch to a different mode |
| `server.getMode()` | Get the current mode name |

## Configuration Reference

### `.agency/config.json`

```json
{
  "name": "string (required)",
  "plugins": ["string[]"],
  "modes": {
    "modeName": ["pattern1", "pattern2"]
  },
  "defaultMode": "string (optional)"
}
```

### Environment Variables

| Variable | Description |
|----------|-------------|
| `AGENCY_NAME` | Override server name |
| `AGENCY_MODE` | Override default mode |

## Troubleshooting

### Server won't start

1. Check that a config file exists
2. Verify config syntax with `npx agency config validate`
3. Check Node.js version (requires 20+)

### Tools not showing up

1. Verify the tool is registered before `start()`
2. Check the current mode includes the tool's namespace
3. Use `server.getMode()` to verify active mode

### Plugin fails to load

1. Check plugin exports the correct interface
2. Verify plugin's `initialize()` doesn't throw
3. Check plugin tools have valid schemas
