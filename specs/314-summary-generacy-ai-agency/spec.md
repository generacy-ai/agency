## Summary

The `@generacy-ai/agency-plugin-spec-kit` npm package needs to include the speckit command `.md` files (currently only in the `claude-plugin-agency-spec-kit` package) so they can be distributed via npm install rather than requiring the Claude Code marketplace plugin mechanism.

## Background

Currently, speckit commands (`specify.md`, `clarify.md`, `plan.md`, `tasks.md`, `implement.md`, etc.) are distributed via a Claude Code marketplace plugin (`claude-plugin-agency-spec-kit`). This approach fails in external developer containers because the marketplace plugin install doesn't reliably materialize files to `~/.claude/commands/`, causing worker containers to crash loop.

## Requirements

- Add the `commands/*.md` files from `packages/claude-plugin-agency-spec-kit/commands/` to `packages/agency-plugin-spec-kit`
- Update the `files` field in `packages/agency-plugin-spec-kit/package.json` to include the command files
- Provide a mechanism (postinstall script or exported utility) to copy commands to `~/.claude/commands/`
- Ensure the command files are included in published npm artifacts
