## Implementation Steps

### Step 1: Move Command Files (FR-001)

Move (not copy) all 9 `.md` files from `packages/claude-plugin-agency-spec-kit/commands/` to `packages/agency-plugin-spec-kit/commands/`. These files are not compiled by TypeScript (outside `src/`), so they ship as-is.

### Step 2: Update package.json (FR-002)

Add `"commands"` to the `files` array:
```json
"files": ["dist", "workflows", "commands"]
```

Add a `bin` entry for the CLI:
```json
"bin": {
  "agency-spec-kit": "./dist/cli.js"
}
```

Add the commands subpath export (FR-004):
```json
"exports": {
  ".": { "import": "./dist/index.js", "types": "./dist/index.d.ts" },
  "./commands": { "import": "./dist/commands.js", "types": "./dist/commands.d.ts" },
  "./package.json": "./package.json"
}
```

### Step 3: Create commands.ts (FR-003 + FR-004)

New module `src/commands.ts`:
- `commandsDir`: Resolved absolute path to the `commands/` directory (using `import.meta.url` to resolve relative to the package)
- `installCommands(targetDir?: string)`: Copies all `.md` files from `commandsDir` to `targetDir` (defaults to `~/.claude/commands/agency-spec-kit/`), always overwriting

### Step 4: Create cli.ts (FR-003)

New module `src/cli.ts`:
- Parses `install-commands` subcommand
- Calls `installCommands()` from `commands.ts`
- Reports files copied to stdout
- Invocation: `npx agency-spec-kit install-commands`

### Step 5: Update index.ts

Re-export `commandsDir` from `./commands.js`.

### Step 6: Add Tests

- Test that `commandsDir` resolves to an existing directory containing `.md` files
- Test that `installCommands()` copies files to a temp directory
- Test that `installCommands()` overwrites existing files

### Step 7: Update claude-plugin-agency-spec-kit

Remove the `commands/` directory from the marketplace plugin package (or leave a README noting deprecation). The npm package is now authoritative.
