## Operations

### read
- Load clarifications.md
- Return structured list of questions with status

### append
- Add new question batch to clarifications.md
- For each question, call Humancy:
  - `humancy.ask_question` for open questions
  - `humancy.request_decision` for multiple choice
- Return question IDs for tracking

### update_answer
- Update specific question with answer
- Mark as answered in clarifications.md
