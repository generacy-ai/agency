## Summary

Enhance the existing humancy plugin to support the three-layer decision model (baseline → protégé → human).

## Related

## Background

The current humancy plugin provides basic human-in-the-loop tools:
- `humancy.ask_question`
- `humancy.request_review`
- `humancy.request_decision`
- `humancy.notify`

With the expanded Humancy vision, decisions now go through a three-layer model where the system shows:
1. **System Baseline** - What AI recommends without human wisdom
2. **Protégé Recommendation** - What the human's trained AI predicts
3. **Human Decision** - The final choice

## Enhancements Needed

### Enhanced Decision Request
```typescript
// Current
humancy.request_decision({
  question: "Redis or Postgres?",
  options: [
    { id: "redis", label: "Redis" },
    { id: "postgres", label: "Postgres" }
  ]
});

// Enhanced
humancy.request_decision({
  question: "Redis or Postgres?",
  options: [
    { 
      id: "redis", 
      label: "Redis",
      tradeoffs: {
        pros: ["Fast", "Built-in TTL"],
        cons: ["Another service to manage"]
      }
    },
    { 
      id: "postgres", 
      label: "Postgres",
      tradeoffs: {
        pros: ["Already have it", "Queryable"],
        cons: ["Slower for sessions"]
      }
    }
  ],
  domain: ["architecture", "backend"],  // For principle matching
  context: {
    projectConstraints: ["prefer-fewer-services"],
    relatedIssue: "#142"
  },
  includeRecommendations: true  // Get baseline + protégé back
});
```

### Enhanced Response
```typescript
// Current response
{ selectedOption: "postgres" }

// Enhanced response
{
  selectedOption: "postgres",

  baseline: {

    confidence: 72,
    reasoning: ["Faster for sessions", "Standard pattern"]

    optionId: "postgres",
    confidence: 85,
    reasoning: ["'Prefer fewer services' principle applies"],

  // Human's final choice
  human: {
    optionId: "postgres",
    matchedProtege: true,
    coaching: null  // No coaching needed when matches
  }
}
```

### New Tools
