# Quickstart: SpecKit Plugin

**Feature**: `170-i1-wire-all-tools`

## Installation

The SpecKit plugin is part of the `@generacy-ai/agency-plugin-spec-kit` package.

```bash
pnpm add @generacy-ai/agency-plugin-spec-kit
```

## Basic Usage

### Loading the Plugin

```typescript
import { createSpecKitPlugin } from '@generacy-ai/agency-plugin-spec-kit';

const agency = createAgency();
const plugin = createSpecKitPlugin();
await agency.loadPlugin(plugin);
```

### Configuration

Configure via Agency config:

```typescript
const config = {
  'plugins.speckit': {
    paths: {
      specs: 'specs',           // Directory for spec artifacts
      templates: '.specify/templates'  // Template directory
    },
    branches: {
      pattern: '{paddedNumber}-{slug}',
      numberPadding: 3,
      maxSlugWords: 4
    },
    backlog: {
      provider: 'github',       // 'github' | 'jira' | 'shortcut' | 'local'
      jira: {                   // Optional: Jira configuration
        baseUrl: 'https://company.atlassian.net',
        projectKey: 'PROJ'
      }
    }
  }
};
```

## Available Tools

### Git Operations

```typescript
// Create a feature branch
await tools.execute('spec_kit.git_ops', {
  operation: 'create_branch',
  branch_name: '123-my-feature'
});

// Get current branch
await tools.execute('spec_kit.git_ops', {
  operation: 'current_branch'
});
```

### Feature Management

```typescript
// Create new feature with spec directory
await tools.execute('spec_kit.create_feature', {
  number: 123,
  short_name: 'my-feature',
  description: 'Feature description'
});

// Get feature paths
await tools.execute('spec_kit.get_paths', {
  branch: '123-my-feature'
});

// Check prerequisites
await tools.execute('spec_kit.check_prereqs', {
  require_spec: true,
  require_plan: false
});
```

### Template Operations

```typescript
// Copy templates to feature directory
await tools.execute('spec_kit.copy_template', {
  templates: ['spec', 'plan', 'tasks'],
  feature_dir: 'specs/123-my-feature'
});

// Update agent context files
await tools.execute('spec_kit.update_agent', {
  feature_dir: 'specs/123-my-feature',
  agent_type: 'claude'
});
```

### Backlog Integration

```typescript
// Get ticket from provider
await tools.execute('spec_kit.get_ticket', {
  ref: '#123'  // or 'PROJ-123' for Jira
});

// Create new ticket
await tools.execute('spec_kit.create_ticket', {
  title: 'My ticket',
  body: 'Description',
  labels: ['enhancement']
});

// Update ticket
await tools.execute('spec_kit.update_ticket', {
  ref: '#123',
  updates: { state: 'closed' }
});
```

### Task Management

```typescript
// Convert tasks.md to GitHub issues
await tools.execute('spec_kit.tasks_to_issues', {
  feature_dir: 'specs/123-my-feature',
  grouping: 'per-story',
  dry_run: true
});
```

### Clarifications

```typescript
// Read clarifications
await tools.execute('spec_kit.manage_clarifications', {
  operation: 'read'
});

// Append questions (triggers Humancy if available)
await tools.execute('spec_kit.manage_clarifications', {
  operation: 'append',
  questions: [
    {
      topic: 'Authentication',
      context: 'Need to decide auth method',
      question: 'Should we use OAuth or JWT?',
      options: [
        { label: 'A', description: 'OAuth 2.0' },
        { label: 'B', description: 'JWT tokens' }
      ]
    }
  ]
});

// Update answer
await tools.execute('spec_kit.manage_clarifications', {
  operation: 'update_answer',
  question_number: 1,
  answer: 'Use OAuth 2.0 for better security'
});
```

## Troubleshooting

### Plugin Not Loading

1. Check that `@generacy-ai/agency` is installed
2. Verify the plugin is loaded after Agency initialization
3. Check console for initialization errors

### Tools Not Available

1. Verify plugin is in the correct mode ('coding' or 'research')
2. Some tools are mode-restricted (e.g., ticket operations require 'coding' mode)
3. Check `plugin.manifest.tools` for the expected tool list

### Provider Errors

1. For GitHub: Ensure `gh` CLI is authenticated (`gh auth status`)
2. For Jira: Verify `JIRA_EMAIL` and `JIRA_API_TOKEN` environment variables
3. For Shortcut: Check `SHORTCUT_API_TOKEN` environment variable

### Clarification Questions Not Sent

1. Humancy plugin must be loaded before SpecKit
2. Check that Humancy tools are available: `humancy.ask_question`, `humancy.request_decision`
3. Questions are still written to `clarifications.md` even without Humancy
