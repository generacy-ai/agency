# Quickstart: GitHub Provider E2E Tests

## Prerequisites

1. **GitHub CLI**: Install and authenticate
   ```bash
   # Install (macOS)
   brew install gh

   # Install (Linux)
   curl -fsSL https://cli.github.com/packages/githubcli-archive-keyring.gpg | sudo dd of=/usr/share/keyrings/githubcli-archive-keyring.gpg
   echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null
   sudo apt update && sudo apt install gh

   # Authenticate
   gh auth login
   ```

2. **Verify Authentication**:
   ```bash
   gh auth status
   # Should show: Logged in to github.com as <username>
   ```

3. **GITHUB_TOKEN** (optional, for GitHubProvider class tests):
   ```bash
   export GITHUB_TOKEN=$(gh auth token)
   ```

## Running Tests

### All E2E Tests

```bash
cd packages/agency-plugin-spec-kit
pnpm test tests/integration/github-flow.test.ts
```

### Specific Test Group

```bash
# Basic operations only
pnpm test tests/integration/github-flow.test.ts -t "Basic Operations"

# Feature creation tests
pnpm test tests/integration/github-flow.test.ts -t "Feature Creation"
```

### With Resource Preservation

```bash
# Keep test issues/branches for debugging
PRESERVE_TEST_RESOURCES=true pnpm test tests/integration/github-flow.test.ts
```

### Watch Mode (for development)

```bash
pnpm test tests/integration/github-flow.test.ts --watch
```

## Troubleshooting

### "gh: command not found"

Install GitHub CLI:
```bash
# macOS
brew install gh

# Or download from https://cli.github.com/
```

### "gh: not authenticated"

Run authentication:
```bash
gh auth login
# Follow prompts to authenticate
```

### Rate Limiting

If you see rate limit errors:
1. Wait for the rate limit window to reset (usually 1 hour)
2. Reduce test parallelism
3. Add `--maxWorkers=1` to run tests sequentially

### Test Resources Not Cleaned Up

If `PRESERVE_TEST_RESOURCES=true` was used:
```bash
# List test issues
gh issue list --search "[E2E Test" --state all

# Close a specific test issue
gh issue close <number>

# Delete test branches
git branch -D <branch-name>
```

## CI/CD Configuration

### GitHub Actions Example

```yaml
- name: Run GitHub E2E Tests
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
  run: |
    cd packages/agency-plugin-spec-kit
    pnpm test tests/integration/github-flow.test.ts
```

### Required Permissions

The CI token needs:
- `issues: write` (create/close issues)
- `contents: write` (create/delete branches)
