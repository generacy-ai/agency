# Implementation Plan: Update canonical workflow templates to use build.validate

**Feature**: Replace hardcoded `pnpm run lint` in workflow templates with discovery-based `build.validate`
**Branch**: `325-problem-canonical-workflow`
**Status**: Complete

## Summary

Update the verification phase in both `speckit-feature.yaml` and `speckit-bugfix.yaml` workflow templates to replace the hardcoded `pnpm run lint` step with `build.validate`. The test step remains separate. This makes verification package-manager-agnostic and expands coverage to include `format:check` and `typecheck` when configured.

## Implementation Approach

### Task 1: Update speckit-feature.yaml verification phase

Replace the `run-lint` step in the verification phase (lines 192–196):

**Before:**
```yaml
- name: run-lint
  uses: verification.check
  with:
    command: pnpm run lint
  continueOnError: true
```

**After:**
```yaml
- name: run-validate
  uses: build.validate
  continueOnError: true
```

The `run-tests` step (lines 186–190) remains unchanged — tests stay separate per clarification Q1.

The `build.validate` tool uses default discovery (no `scripts` parameter), which finds `lint`, `format:check`, and `typecheck` automatically per clarification Q2.

### Task 2: Update speckit-bugfix.yaml verification phase

Apply the identical change to the bugfix workflow verification phase (lines 155–166). Same transformation as Task 1.

### Task 3: Verify changes

- Grep both files to confirm no remaining `pnpm` references in verification phases
- Confirm `build.validate` is present in both templates
- Confirm `run-tests` step is preserved in both templates

## Key Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Test step handling | Keep separate from `build.validate` | Tests have different semantics: longer-running, env-dependent (Q1) |
| Discovery scope | Default (no `scripts` param) | Expanded scope is the whole point — catch format:check, typecheck (Q2) |
| Cross-plugin reference | Implicit via engine | Workflow engine resolves tools across all loaded plugins (Q3) |
| Step name | `run-validate` (replaces `run-lint`) | Reflects broader scope — validation includes lint, format, typecheck |
