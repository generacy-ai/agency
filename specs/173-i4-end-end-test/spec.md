## Test Scenarios

### Scenario 1: Create and Retrieve
```typescript
test('local provider creates and retrieves tickets', async () => {
  const created = await callTool('spec_kit.create_ticket', {
    title: 'Test Feature',
    body: 'Description here',
  });
  expect(created.ref.id).toMatch(/^LOCAL-\d{3}$/);
  
  const retrieved = await callTool('spec_kit.get_ticket', {
    ref: created.ref.id,
  });
  expect(retrieved.title).toBe('Test Feature');
});
```

### Scenario 2: Persistence
```typescript
test('local tickets persist to file', async () => {
  await callTool('spec_kit.create_ticket', { title: 'Persistent' });
  
  const storeContent = await fs.readFile('.specify/local-tickets.json', 'utf-8');
  const store = JSON.parse(storeContent);
  expect(store.tickets).toHaveProperty('LOCAL-001');
});
```

### Scenario 3: Offline Full Workflow
```typescript
test('full workflow works offline', async () => {
  // No network required
  const feature = await callTool('spec_kit.create_feature', {
    description: 'Offline feature',
  });
  const ticket = await callTool('spec_kit.create_ticket', {
    title: feature.branch,
  });
  expect(ticket.ref.provider).toBe('local');
});
```
