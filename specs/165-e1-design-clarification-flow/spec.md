## Clarification Flow

```
┌─────────────────────────────────────────────────────────────────┐
│ /agency-spec-kit:clarify command                                │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 1. Agent analyzes spec.md for underspecified areas              │
│ 2. Agent generates clarification questions                      │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 3. Call spec_kit.manage_clarifications(operation: 'append')     │
│    - Stores questions in clarifications.md                      │
│    - Calls humancy.ask_question for each question               │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 4. Human answers in Humancy decision queue (VS Code panel)      │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 5. Answers returned via Humancy                                 │
│ 6. spec_kit.manage_clarifications(operation: 'update_answer')   │
│    - Updates clarifications.md with answers                     │
└─────────────────────────────────────────────────────────────────┘
```

## Humancy Integration Points

| Operation | Humancy Tool | Parameters |
|-----------|--------------|------------|
| Single question | `humancy.ask_question` | question, context, timeout |
| Multiple choice | `humancy.request_decision` | question, options, context |
| Question batch | Multiple `humancy.ask_question` calls | Queued in decision queue |

## Design Decisions to Document

1. **Question batching**: Should we ask all questions at once or one at a time?
2. **Timeout handling**: What happens if a question times out?
3. **Partial answers**: Can we proceed with some questions unanswered?
4. **Answer persistence**: How do we correlate Humancy responses with local storage?
