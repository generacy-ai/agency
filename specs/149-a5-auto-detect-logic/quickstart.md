# Quickstart: Ticket Reference Detection

**Feature**: A5: Auto-detect logic for ticket refs

## Installation

The detection utility is part of `@generacy/agency-plugin-spec-kit`:

```bash
pnpm add @generacy/agency-plugin-spec-kit
```

## Usage

### Basic Detection

```typescript
import { detectTicketRef } from '@generacy/agency-plugin-spec-kit';

// GitHub URL
const ref1 = detectTicketRef(
  'https://github.com/owner/repo/issues/123',
  'github'
);
// => { provider: 'github', id: '123', url: '...', raw: '...' }

// Jira shorthand
const ref2 = detectTicketRef('PROJ-456', 'github');
// => { provider: 'jira', id: 'PROJ-456', raw: 'PROJ-456' }

// GitHub shorthand
const ref3 = detectTicketRef('#789', 'github');
// => { provider: 'github', id: '789', raw: '#789' }

// Local provider
const ref4 = detectTicketRef('LOCAL-001', 'github');
// => { provider: 'local', id: '001', raw: 'LOCAL-001' }

// Bare number (uses default provider)
const ref5 = detectTicketRef('42', 'jira');
// => { provider: 'jira', id: '42', raw: '42' }

// Invalid input
const ref6 = detectTicketRef('not-a-ticket', 'github');
// => null
```

### With Provider Registry

```typescript
import { detectTicketRef, getProvider } from '@generacy/agency-plugin-spec-kit';

async function fetchTicket(input: string) {
  const ref = detectTicketRef(input, 'github');
  if (!ref) {
    throw new Error(`Invalid ticket reference: ${input}`);
  }

  const provider = getProvider(ref.provider);
  return await provider.getTicket(ref.raw);
}
```

## Supported Formats

| Input Format | Example | Detected Provider |
|--------------|---------|-------------------|
| GitHub URL | `https://github.com/o/r/issues/123` | github |
| GitHub PR URL | `https://github.com/o/r/pull/456` | github |
| GitHub shorthand | `#123` or `owner/repo#123` | github |
| Jira URL | `https://co.atlassian.net/browse/PROJ-123` | jira |
| Jira key | `PROJ-123` | jira |
| Shortcut URL | `https://app.shortcut.com/ws/story/789` | shortcut |
| Shortcut key | `sc-123` | shortcut |
| Local key | `LOCAL-001` | local |
| Bare number | `42` | (default provider) |

## API Reference

### detectTicketRef

```typescript
function detectTicketRef(
  input: string,
  defaultProvider: BacklogProviderName
): TicketRef | null;
```

**Parameters**:
- `input`: User-provided ticket reference string
- `defaultProvider`: Provider to use for ambiguous references (bare numbers)

**Returns**:
- `TicketRef` object if input is valid
- `null` if input cannot be parsed

### TicketRef Type

```typescript
interface TicketRef {
  provider: string;  // 'github', 'jira', 'shortcut', 'local'
  id: string;        // Ticket identifier
  url?: string;      // Full URL if available
  raw: string;       // Original input
}
```

## Troubleshooting

### Returns null for valid input

- Check that URLs are complete and properly formatted
- Jira keys must be uppercase: `PROJ-123` not `proj-123`
- Shortcut keys must have `sc-` prefix: `sc-123` not just `123`

### Wrong provider detected

Detection follows priority order:
1. URLs (most specific)
2. Shortcut pattern (`sc-XXX`)
3. Jira pattern (`PROJ-XXX`)
4. Local pattern (`LOCAL-XXX`)
5. GitHub shorthand (`#XXX`)
6. Bare numbers (uses default)

If `SC-123` is detected as Shortcut but you meant Jira, use the full URL instead.
