## Implementation Approach

### Phase 1: Add LOCAL Pattern Support

Add detection for `LOCAL-xxx` format in `detect-ticket-ref.ts`:

```typescript
const LOCAL_PATTERN = /^LOCAL-(\d+)$/i;

function detectLocal(input: string): TicketRef | null {
  const match = input.match(LOCAL_PATTERN);
  if (match && match[1]) {
    return {
      provider: 'local',
      id: match[1],
      raw: input,
    };
  }
  return null;
}
```

Insert this check before bare number detection (after Jira/Shortcut checks).
