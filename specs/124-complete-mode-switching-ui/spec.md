# Feature Specification: Complete Mode Switching UI in VS Code extension

**Branch**: `124-complete-mode-switching-ui` | **Date**: 2026-01-24 | **Status**: Draft

## Summary

## Overview

The mode switching functionality in the Agency VS Code extension has stub implementations that need to be completed. The core mode system in the MCP server is fully implemented, but the UI commands are stubs.

## Current State

From exploring the codebase, these commands are registered but stubbed:
- `agency.switchMode` - Switch to a different mode
- `agency.viewModeTools` - View tools available in a mode

The `ModeTreeProvider` exists but may not be fully wired up.

## Requirements

### Mode Switching Command
- Show quick pick with available modes from config
- Display mode description and tool count
- Switch mode via MCP client
- Update status bar and tree views
- Persist last-used mode

### Mode Tools View
- Tree view showing tools grouped by mode
- Indicate current mode
- Show which tools are enabled/disabled per mode
- Click to switch mode

### Status Bar Integration
- Show current mode in status bar
- Click to open mode picker
- Update when mode changes

## Technical Notes

- Mode configuration comes from `agency.config.json`
- MCP server already handles mode switching
- Need to wire UI to existing ModeService

## Acceptance Criteria

- [ ] Can switch modes via command palette
- [ ] Status bar shows current mode
- [ ] Mode tree view displays correctly
- [ ] Tools list updates when mode changes
- [ ] Mode persists across VS Code restarts
