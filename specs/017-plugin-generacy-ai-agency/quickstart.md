# Quickstart: @generacy-ai/agency-plugin-npm

## Installation

The plugin is included in the Agency monorepo. To use it in your Agency configuration:

```json
{
  "plugins": ["@generacy-ai/agency-plugin-npm"]
}
```

## Configuration

Optional configuration in your Agency config file:

```json
{
  "pluginOptions": {
    "@generacy-ai/agency-plugin-npm": {
      "packageManager": "auto",
      "scripts": {
        "build": "build",
        "test": "test",
        "lint": "lint",
        "format": "format",
        "test:integration": "test:integration",
        "test:e2e": "test:e2e",
        "test:coverage": "coverage"
      }
    }
  }
}
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| packageManager | `'auto'` \| `'npm'` \| `'yarn'` \| `'pnpm'` | `'auto'` | Package manager to use |
| scripts | object | See above | Script name mappings |

## Available Tools

### Build Tools

| Tool | Description |
|------|-------------|
| `build.install_dependencies` | Install project dependencies |
| `build.compile` | Run build/compile script |
| `build.lint` | Run linter |
| `build.format` | Run code formatter |

### Test Tools

| Tool | Description |
|------|-------------|
| `test.run_unit` | Run unit tests |
| `test.run_integration` | Run integration tests |
| `test.run_e2e` | Run end-to-end tests |
| `test.run_coverage` | Run tests with coverage |

## Monorepo Support

All tools accept `cwd` and `workspace` parameters for monorepo projects.

### Using cwd

Run in specific directory:
```json
{
  "tool": "build.compile",
  "params": { "cwd": "./packages/my-package" }
}
```

### Using workspace

Target specific workspace:
```json
{
  "tool": "test.run_unit",
  "params": { "workspace": "@myorg/my-package" }
}
```

## Troubleshooting

### Package Manager Not Detected

**Problem**: "Could not detect package manager"

**Solution**: Ensure your project has one of:
- `package-lock.json` (npm)
- `yarn.lock` (yarn)
- `pnpm-lock.yaml` (pnpm)

Or configure explicitly:
```json
{ "packageManager": "npm" }
```

### Script Not Found

**Problem**: "Script not found: 'build:custom'"

**Solution**: Either:
1. Add the script to your package.json
2. Configure the correct script name:
```json
{
  "scripts": { "build": "build:custom" }
}
```

### Workspace Not Found

**Problem**: "Workspace not found: '@myorg/missing'"

**Solution**: Verify the workspace exists in your:
- `pnpm-workspace.yaml` (pnpm)
- `package.json` workspaces field (npm/yarn)
