## Type Design Principles

1. **Explicit over Implicit**: Prefer explicit types over inference for public APIs
2. **Immutability**: Use `readonly` for data that shouldn't be mutated
3. **Discriminated Unions**: Use tagged unions for state machines
4. **Branded Types**: Use nominal typing where identity matters
5. **Zod Integration**: Provide runtime validation for external data
