## Implementation Details

### Icons

**Design Approach**:
- Minimalist, line-based SVG icons
- Uses `currentColor` for stroke to inherit theme colors
- Consistent stroke-width (1.5) and line caps/joins
- 24x24 viewBox for clarity at all sizes

**Icon Semantics**:
1. **agency.svg**: Connected network symbol (central node with satellite nodes)
   - Represents the agency concept (multiple agents working together)
2. **plugin.svg**: Puzzle piece symbol
   - Standard metaphor for extensibility
3. **tool.svg**: Wrench/tool symbol
   - Represents individual MCP tools
4. **activity.svg**: Activity/pulse symbol
   - Represents agent activity and execution
5. **container.svg**: Box/container symbol
   - Represents plugin containers

### Styles (webview.css)

**Design System**:
- Uses VS Code CSS variables for automatic theme adaptation
- Covers: light, dark, high-contrast themes
- Base reset and typography
- Container layouts (fixed-width and fluid)
- Flexbox utilities
- Component styles for common webview elements

**Key Variables Used**:
- `--vscode-font-family`, `--vscode-font-size`, `--vscode-font-weight`
- `--vscode-foreground`, `--vscode-editor-background`
- `--vscode-button-*`, `--vscode-input-*`, `--vscode-list-*`
- `--vscode-badge-*`, `--vscode-panel-*`

**Sections**:
1. Base reset & typography
2. Container & layout utilities
3. Typography scale (headings, paragraphs)
4. Interactive elements (buttons, inputs, links)
5. List components
6. Badge components
7. Panel/card components
8. Utility classes (spacing, borders)
