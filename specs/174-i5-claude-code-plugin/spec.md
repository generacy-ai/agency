## Commands to Implement

### /agency-spec-kit:plan
Generate implementation plan from spec.md
- Prereqs: spec.md exists, clarifications resolved
- Creates: plan.md
- Updates: agent context files

### /agency-spec-kit:tasks
Generate tasks from plan.md
- Prereqs: plan.md exists
- Creates: tasks.md
- Formats: task list with dependencies

### /agency-spec-kit:taskstoissues
Convert tasks.md to backlog tickets
- Prereqs: tasks.md exists
- Uses: BacklogProvider
- Supports: dry-run mode

### /agency-spec-kit:implement
Guidance for implementing tasks
- Prereqs: tasks.md exists
- Shows: current task, dependencies, context

### /agency-spec-kit:checklist
Generate custom quality checklist
- Prereqs: spec.md or plan.md exists
- Creates: checklists/{name}.md

### /agency-spec-kit:analyze
Read-only analysis of spec artifacts
- Checks: consistency across spec, plan, tasks
- Reports: issues, warnings, suggestions
