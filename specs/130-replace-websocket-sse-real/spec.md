# Feature Specification: Replace WebSocket with SSE for real-time updates across platform

**Branch**: `130-replace-websocket-sse-real` | **Date**: 2026-01-24 | **Status**: Draft

## Summary

## Overview

Replace WebSocket-based real-time updates with Server-Sent Events (SSE) across all platform components to simplify infrastructure and scaling.

## Rationale

- SSE works over standard HTTP/2 - no special infrastructure needed
- Scales with regular HTTP load balancers (no sticky sessions)
- Auto-reconnection built into the protocol
- Cloud Run, Lambda, etc. handle it natively
- Simpler to debug (it's just HTTP)
- The communication pattern is unidirectional (server → client) which is exactly what SSE is designed for

### API Design

Replace:
```
wss://api.generacy.ai/ws/decisions
```

With:
```
GET /api/humancy/decisions/events          # SSE stream for all user's decisions
GET /api/humancy/decisions/{id}/events     # SSE stream for specific decision
```

SSE event types:
- `decision:created`
- `decision:updated`
- `decision:resolved`
