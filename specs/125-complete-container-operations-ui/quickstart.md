# Quickstart: Container Operations UI

## Overview

The Container Operations UI allows you to manage dev containers directly from the VS Code sidebar. You can start, stop, rebuild containers, and view their logs without leaving the editor.

## Prerequisites

- Docker installed and running
- VS Code with the Agency extension installed
- A workspace with a `devcontainer.json` configuration

## Getting Started

### 1. Open the Containers View

The Containers view is available in the Agency sidebar. Click on the Agency icon in the Activity Bar, then expand the "Containers" section.

### 2. Start a Container

**From Tree View:**
1. Right-click on a stopped container
2. Select "Start Container"
3. Wait for the progress notification to complete

**From Command Palette:**
1. Open Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)
2. Type "Agency: Start Container"
3. Select a container from the list (if not already selected in tree view)

**Requirements:**
- A `devcontainer.json` must exist in your workspace
- The container must be in a stopped/exited state

### 3. Stop a Container

**From Tree View:**
1. Right-click on a running container
2. Select "Stop Container"
3. MCP connection will be automatically disconnected

**From Command Palette:**
1. Open Command Palette
2. Type "Agency: Stop Container"
3. Select a running container

### 4. Rebuild a Container

**From Tree View:**
1. Right-click on a dev container
2. Select "Rebuild Container"
3. Confirm the action
4. Wait for the rebuild to complete

**Notes:**
- Only available for dev containers (with devcontainer labels)
- Uses VS Code's Remote Containers rebuild when connected
- Falls back to stop + remove + reopen for external containers

### 5. View Container Logs

**From Tree View:**
1. Right-click on any container
2. Select "View Logs"
3. A panel will open with streaming logs

**Log Features:**
- Real-time streaming for running containers
- Text search filter
- Log level filter (stdout/stderr)
- Auto-scroll toggle

## MCP Connection Integration

The extension automatically manages MCP connections based on container state:

- **Container Starts**: MCP connection is automatically established (if container has MCP server)
- **Container Stops**: MCP connection is gracefully disconnected
- **Container Rebuilds**: MCP connection is restored after rebuild completes

No manual intervention is required for MCP connection management.

## Troubleshooting

### "Docker not found" Error

Ensure Docker is installed and the `docker` command is available in your PATH:
```bash
docker --version
```

### "No devcontainer.json found" Error

The start and rebuild commands require a devcontainer.json in your workspace:
```
.devcontainer/devcontainer.json  # Standard location
.devcontainer.json               # Alternative location
```

### Container Won't Start

1. Check if Docker is running
2. Verify devcontainer.json is valid JSON
3. Check Docker logs: `docker logs <container-name>`

### Logs Not Streaming

1. Ensure the container is running
2. Check for Docker CLI errors in the Output panel
3. Try refreshing the Containers view

### MCP Connection Issues

1. Verify the container has MCP server installed
2. Check if the agency.mcp-server label is set
3. View MCP connection status in the status bar

## Commands Reference

| Command | Description |
|---------|-------------|
| `agency.startContainer` | Start a dev container |
| `agency.stopContainer` | Stop a running container |
| `agency.rebuildContainer` | Rebuild a dev container |
| `agency.viewContainerLogs` | Open log viewer for a container |
| `agency.refreshContainers` | Refresh the containers list |

## Keyboard Shortcuts

No default keyboard shortcuts are assigned. You can add custom shortcuts in VS Code's keyboard shortcuts settings:

1. Open Keyboard Shortcuts (`Ctrl+K Ctrl+S`)
2. Search for "Agency"
3. Assign shortcuts to container commands
