# Feature Specification: Update Agency core to use Latency facets

**Branch**: `211-update-agency-core-use` | **Date**: 2026-02-04 | **Status**: Draft

## Summary

## Description

Refactor `@generacy-ai/agency` to depend on `@generacy-ai/latency` for facet-based composition. Agency plugins will declare what they provide/require instead of directly importing from other components.

## Tasks

- [ ] Add `@generacy-ai/latency` as dependency
- [ ] Implement `PluginContext` for Agency
- [ ] Update plugin registration to use facet declarations (`provides`/`requires`)
- [ ] Implement facet resolution at startup

- [ ] Register Agency-specific facet providers
- [ ] Ensure existing functionality preserved (no regressions)
- [ ] Update tests

## Before / After

### Before
```typescript
import { HumancyClient } from '@generacy-ai/agency';
// Direct knowledge of Humancy
```

### After
```typescript
import { DecisionHandler } from '@generacy-ai/latency';
export const manifest: PluginManifest = {
  requires: [{ facet: 'DecisionHandler' }],
};
// Only knows the facet
```

## Extension Pattern

Agency plugins that have Latency implementations should extend them:

```typescript
import { GitHubIssuesPlugin } from '@generacy-ai/latency-plugin-github-issues';

export class AgencyGitHubIssuesPlugin extends GitHubIssuesPlugin {
  register(context: AgencyPluginContext) {
    context.provide('IssueTracker', this, 'github');
    context.registerTool({ name: 'github.issues.get', ... });
  }
}
```
