# Implementation Plan: ActivityService

**Feature**: ActivityService - Real-time monitoring of agent tool invocations
**Branch**: `054-tg-015-us3-activityservice`
**Status**: Complete

## Summary

Implement `ActivityService` for the Agency VS Code extension that subscribes to the Agency event stream to monitor tool invocations in real-time. The service maintains an in-memory buffer of events, supports filtering via the `ActivityFilter` interface, and calculates activity statistics.

## Key Interfaces

The service uses existing types from `src/types/activity.ts`:
- `ToolCallEvent` - Represents a tool invocation event
- `ActivityFilter` - Filter criteria for querying events

## Implementation Details

### 1. Ring Buffer for Event Storage
- Fixed-size circular buffer to prevent memory growth
- Default size: 1000 events (configurable)
- FIFO eviction when buffer is full
- O(1) insertion, O(n) filtering

### 2. Event Filtering
Implement filter matching for all `ActivityFilter` fields:
- `toolName` - Partial string match (case-insensitive)
- `namespace` - Exact match
- `pluginId` - Exact match
- `agentId` - Exact match
- `status` - Single or array match
- `isError` - Boolean match
- `startTime`/`endTime` - Range match
- `containerId` - Exact match
- `limit`/`offset` - Pagination

### 3. Statistics Calculation
Compute on-demand from buffered events:
- Total/success/error/timeout/pending counts
- Average/median duration
- Calls per minute (based on time range)
- Top tools by call count

### 4. Event Emission
- `onToolCall` - Fired for each new event
- `onBatch` - Fired with array of events (for bulk updates)
