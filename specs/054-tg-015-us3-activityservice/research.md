## Technology Decisions

### 1. Event Buffer Implementation

**Decision**: Custom ring buffer (circular buffer)

**Alternatives Considered**:
| Option | Pros | Cons |
|--------|------|------|
| Array with shift() | Simple | O(n) removal, memory reallocation |
| Array with splice() | Simple | O(n) removal |
| Ring buffer | O(1) add/remove | More complex indexing |
| Deque library | Battle-tested | External dependency |

**Rationale**: Ring buffer provides O(1) insertion with bounded memory. The implementation is straightforward and avoids external dependencies. The complexity is manageable for a fixed-size buffer.

### 2. Event Emission Pattern

**Decision**: VS Code-style EventEmitter (custom implementation)

**Rationale**: Following the pattern established in `McpClientService.ts`:
- Custom `EventEmitter<T>` class
- Returns `vscode.Disposable` for subscription cleanup
- Consistent with VS Code extension patterns

### 3. Statistics Calculation

**Decision**: On-demand calculation from buffer

**Alternatives Considered**:
| Option | Pros | Cons |
|--------|------|------|
| On-demand | Fresh data, simple | Recalculates each time |
| Cached with invalidation | Fast reads | Complex invalidation |
| Incremental updates | Efficient | Very complex, edge cases |

**Rationale**: With a max buffer of 1000 events, on-demand calculation is fast enough (< 50ms target). Incremental updates would add significant complexity for minimal benefit.

### 4. Filter Matching

**Decision**: Sequential filter application

**Rationale**: Simple, predictable behavior. For the expected data sizes (1000 events max), a single pass through the buffer is sufficient.

### Ring Buffer Pattern

```typescript
class RingBuffer<T> {
  private items: T[];
  private head = 0;     // Next write position
  private count = 0;    // Current size

  constructor(private maxSize: number) {
    this.items = new Array(maxSize);
  }

  push(item: T): T | undefined {
    const evicted = this.count === this.maxSize ? this.items[this.head] : undefined;
    this.items[this.head] = item;
    this.head = (this.head + 1) % this.maxSize;
    this.count = Math.min(this.count + 1, this.maxSize);
    return evicted;
  }

  toArray(): T[] {
    if (this.count === 0) return [];
    const result: T[] = [];
    const start = this.count < this.maxSize ? 0 : this.head;
    for (let i = 0; i < this.count; i++) {
      result.push(this.items[(start + i) % this.maxSize]);
    }
    return result;
  }
}
```
