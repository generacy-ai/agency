# Quickstart: agency-spec-kit Claude Plugin

## Installation

1. Add the plugin to your Claude Code configuration:
   ```bash
   # In your project's .claude/settings.json or global settings
   {
     "plugins": [
       "path/to/claude-plugin-agency-spec-kit"
     ]
   }
   ```

2. Ensure the MCP server dependency is configured:
   ```bash
   # In your MCP configuration
   {
     "mcpServers": {
       "speckit": {
         "command": "npx",
         "args": ["@generacy-ai/agency-plugin-spec-kit"]
       }
     }
   }
   ```

## Available Commands

| Command | Description |
|---------|-------------|
| `/speckit:specify <description>` | Create a new feature specification |
| `/speckit:clarify` | Identify ambiguities and gather clarifications |
| `/speckit:plan` | Generate implementation plan from spec |
| `/speckit:tasks` | Generate task list from plan |
| `/speckit:taskstoissues` | Convert tasks to GitHub issues |
| `/speckit:implement` | Execute implementation tasks |
| `/speckit:checklist` | Generate quality checklist |
| `/speckit:analyze` | Run consistency analysis |
| `/speckit:constitution` | Manage project governance principles |

## Usage Examples

### Start a new feature
```
/speckit:specify Add user authentication with OAuth2 support
```

### Full workflow
```
/speckit:specify <description>
/speckit:clarify
/speckit:plan
/speckit:tasks
/speckit:implement
```

## Troubleshooting

### Commands not recognized
- Verify the plugin path is correct in settings
- Check that plugin.json is valid JSON
- Restart Claude Code after adding plugin

### MCP tools not available
- Ensure the MCP server is configured and running
- Check MCP server logs for errors
- Verify the server name matches `requires.mcp` in plugin.json
