### branchExists Implementation
```typescript
// Check local first, then remote
async function branchExists(name: string, cwd?: string): Promise<boolean> {
  const git = await getGit(cwd);
  const branches = await git.branchLocal();
  if (branches.all.includes(name)) return true;

  // Check remote (origin/)
  const remoteBranches = await git.branch(['-r']);
  return remoteBranches.all.includes(`origin/${name}`);
}
```

### SimpleGit Instance Management
- Create new instance per operation for thread safety
- Use `process.cwd()` as default when `cwd` not provided
- Validate git repository exists before operations
