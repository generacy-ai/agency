# Quickstart: Git Utilities

## Installation

The git utilities are part of the `@generacy-ai/agency` package:

```bash
pnpm add @generacy-ai/agency
```

## Usage

### Basic Usage

```typescript
import {
  getCurrentBranch,
  getStatus,
  isGitRepo,
  branchExists,
  createBranch,
  checkout,
  fetch
} from '@generacy-ai/agency';

// Check if current directory is a git repo
if (await isGitRepo()) {
  const branch = await getCurrentBranch();
  console.log(`Current branch: ${branch}`);
}

// Get repository status
const status = await getStatus();
console.log(`Clean: ${status.isClean}`);
console.log(`Branch: ${status.currentBranch}`);
```

### Working with Branches

```typescript
// Check if branch exists (local or remote)
const exists = await branchExists('feature/my-branch');

// Create a new branch from current HEAD
await createBranch('feature/new-branch');

// Create a new branch from specific ref
await createBranch('feature/from-main', 'main');

// Switch branches
await checkout('develop');
```

### Fetching Updates

```typescript
// Fetch all remotes with prune (default)
await fetch();

// Fetch without pruning
await fetch({ prune: false });

// Fetch only default remote
await fetch({ all: false });
```

### Custom Working Directory

All functions accept an optional `cwd` parameter:

```typescript
const branch = await getCurrentBranch('/path/to/repo');
const status = await getStatus('/another/repo');
```

## API Reference

| Function | Description |
|----------|-------------|
| `isGitRepo(cwd?)` | Check if directory is git repo |
| `getGit(cwd?)` | Get SimpleGit instance |
| `getCurrentBranch(cwd?)` | Get current branch name |
| `branchExists(name, cwd?)` | Check if branch exists |
| `createBranch(name, from?, cwd?)` | Create and checkout branch |
| `checkout(branch, cwd?)` | Switch branches |
| `fetch(options?, cwd?)` | Fetch from remotes |
| `getStatus(cwd?)` | Get working tree status |

## Error Handling

All functions throw errors on failure:

```typescript
try {
  await checkout('non-existent-branch');
} catch (error) {
  console.error('Checkout failed:', error.message);
}
```

## GitStatus Type

```typescript
interface GitStatus {
  isClean: boolean;      // No uncommitted changes
  currentBranch: string; // Branch name or "HEAD"
  hasChanges: boolean;   // Inverse of isClean
}
```

## Troubleshooting

### "Not a git repository"
- Ensure the directory contains a `.git` folder
- Check the `cwd` parameter is correct

### Branch operations fail
- Verify you have git credentials configured
- Check for uncommitted changes that may block operations

### Fetch fails
- Verify network connectivity
- Check remote 'origin' is configured
