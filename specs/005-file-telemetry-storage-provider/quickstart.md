# Quickstart: File Telemetry Storage Provider

## Installation

The file storage provider is included in the `@generacy-ai/agency` package. No additional installation required.

## Basic Usage

### Daily Mode (Default)

```typescript
import { TelemetryManager, FileStorageProvider } from '@generacy-ai/agency';

// Create telemetry manager
const telemetry = new TelemetryManager({ enabled: true });

// Register file provider with defaults
const fileProvider = new FileStorageProvider({
  directory: '.agency/telemetry',
  mode: 'daily',
});

await telemetry.registerProvider(fileProvider);

// Events are now persisted to daily files
// e.g., .agency/telemetry/2025-01-16.jsonl
```

### Session Mode

```typescript
const fileProvider = new FileStorageProvider({
  directory: '.agency/telemetry',
  mode: 'session',
  sessionId: 'my-workflow-123',
});

await telemetry.registerProvider(fileProvider);

// Events written to: .agency/telemetry/sessions/my-workflow-123.jsonl
```

## Configuration

### Full Options

```typescript
const fileProvider = new FileStorageProvider({
  // Output directory (default: ".agency/telemetry")
  directory: '/var/log/agency/telemetry',

  // Rotation mode: "daily" or "session"
  mode: 'daily',

  // Session ID (required for session mode)
  sessionId: undefined,

  // Days to keep logs before cleanup (default: 30)
  maxAgeDays: 30,

  // Compress old files during rotation (default: false)
  compress: true,
});
```

### Configuration File

In `.agency/config.json`:

```json
{
  "telemetry": {
    "enabled": true,
    "providers": ["file"],
    "file": {
      "directory": ".agency/telemetry",
      "mode": "daily",
      "maxAgeDays": 30,
      "compress": false
    }
  }
}
```

## Querying Events

```typescript
// Query by date range
const events = await fileProvider.query({
  startTime: '2025-01-15T00:00:00Z',
  endTime: '2025-01-16T23:59:59Z',
});

// Query by tool name
const readEvents = await fileProvider.query({
  toolName: 'read_file',
  limit: 100,
});

// Query by session
const sessionEvents = await fileProvider.query({
  sessionId: 'my-workflow-123',
});
```

## File Management

### List Log Files

```typescript
const files = await fileProvider.getLogFiles();
// Returns: ['2025-01-16.jsonl', '2025-01-15.jsonl', ...]
```

### Rotate Old Logs

```typescript
// Use configured maxAgeDays
const result = await fileProvider.rotateOldLogs();

// Or specify custom threshold
const result = await fileProvider.rotateOldLogs(7);

console.log(result);
// {
//   deletedCount: 5,
//   compressedCount: 10,
//   deletedFiles: [...],
//   compressedFiles: [...],
//   bytesReclaimed: 1024000
// }
```

## File Format

Events are stored in JSONL format (one JSON object per line):

```
{"id":"uuid-1","timestamp":"2025-01-16T10:00:00Z","toolName":"read_file",...}
{"id":"uuid-2","timestamp":"2025-01-16T10:00:01Z","toolName":"write_file",...}
```

## Troubleshooting

### Events Not Being Written

1. Check telemetry is enabled: `telemetry.isEnabled()`
2. Verify directory exists and is writable
3. Check console for warning messages

### Query Returns Empty Results

1. Verify date range covers the target time period
2. Check file exists in the directory
3. Ensure events were actually recorded

### Permission Errors

The provider logs warnings but does not throw on write failures. Check:
1. Directory permissions (`chmod 755 .agency/telemetry`)
2. Disk space availability
3. File ownership
