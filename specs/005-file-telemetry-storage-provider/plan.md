# Implementation Plan: File Telemetry Storage Provider

**Feature**: File-based storage provider for persistent telemetry logs
**Branch**: `005-file-telemetry-storage-provider`
**Status**: Complete

## Summary

Implement a `FileStorageProvider` class that persists telemetry events to JSONL files. The provider supports daily file rotation (default) and per-session file modes, with configurable cleanup and optional compression of old files. Events are appended to files in a streaming fashion for minimal latency.

## Implementation Approach

### 1. FileStorageProvider Class

Create a new `FileStorageProvider` class implementing `TelemetryStorageProvider`:

```typescript
// File: packages/agency/src/telemetry/providers/file.ts

export class FileStorageProvider implements TelemetryStorageProvider {
  readonly name = 'file';

  constructor(options: FileProviderOptions);

  // Required interface methods
  initialize(): Promise<void>;
  shutdown(): Promise<void>;
  record(event: ToolCallEvent): Promise<void>;
  query(filter: TelemetryFilter): Promise<ToolCallEvent[]>;

  // Extended methods for file management
  getLogFiles(): Promise<string[]>;
  rotateOldLogs(maxAgeDays: number): Promise<RotationResult>;
}
```

### 2. File Naming Strategy

| Mode | File Pattern | Example |
|------|-------------|---------|
| Daily | `{directory}/YYYY-MM-DD.jsonl` | `.agency/telemetry/2025-01-16.jsonl` |
| Session | `{directory}/sessions/{sessionId}.jsonl` | `.agency/telemetry/sessions/abc123.jsonl` |

### 3. Configuration Schema

```typescript
export interface FileProviderOptions {
  directory?: string;        // Default: ".agency/telemetry"
  mode?: "daily" | "session"; // Default: "daily"
  sessionId?: string;        // Required for session mode
  maxAgeDays?: number;       // Default: 30
  compress?: boolean;        // Default: false
}
```

### 4. Error Handling Strategy

- **Write failures**: Log warning, continue operation (best-effort)
- **Query failures**: Propagate error (user needs to know)
- **Validation errors**: Throw on construction (fail fast)

### 5. Query Implementation

Query scans relevant files based on date range:
1. List all `.jsonl` files in directory
2. Filter files by date range (parse filename for daily mode)
3. Stream-read each file line by line
4. Parse JSON and apply filters
5. Apply limit/offset pagination

## Key Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| File format | JSONL | Append-only friendly, line-by-line parsing |
| Concurrency | Single-process | Simplicity; Agency runs one per container |
| Compression trigger | Explicit rotateOldLogs() | Consumer controls I/O timing |
| Write strategy | Append + flush | Low latency, durability |
| Error handling | Log warnings | Telemetry shouldn't crash the agent |
