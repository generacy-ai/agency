# Research: File Telemetry Storage Provider

## Technology Decisions

### JSONL Format

**Decision**: Use JSON Lines (JSONL) format for storage.

**Rationale**:
- Append-only writes (no need to parse/modify existing content)
- Line-by-line parsing (low memory footprint for large files)
- Human-readable for debugging
- No schema overhead per event (JSON is self-describing)
- Industry standard for log files (supported by many tools)

**Alternatives Considered**:
- **SQLite**: More complex, requires file locking, overkill for append-only logs
- **CSV**: Not suitable for nested data structures
- **Binary formats**: Not human-readable, harder to debug

### File Rotation Strategy

**Decision**: Date-based rotation with optional session mode.

**Rationale**:
- Daily files provide natural time-based boundaries
- Session files enable correlation with workflow tracking
- No size-based rotation needed (daily reset handles growth)

### Node.js File API

**Decision**: Use `fs/promises` with `appendFile` for writes.

**Rationale**:
- `appendFile` is atomic at the OS level for small writes
- Promise-based API integrates cleanly with async/await
- No external dependencies needed

**Compression Library**: Node.js built-in `zlib` for gzip compression.

## Implementation Patterns

### Streaming File Read for Queries

```typescript
import { createReadStream } from 'node:fs';
import { createInterface } from 'node:readline';

async function* readJsonlFile(path: string): AsyncGenerator<ToolCallEvent> {
  const stream = createReadStream(path);
  const rl = createInterface({ input: stream });

  for await (const line of rl) {
    if (line.trim()) {
      yield JSON.parse(line);
    }
  }
}
```

### Date Extraction from Filename

```typescript
function extractDateFromFilename(filename: string): Date | null {
  const match = filename.match(/^(\d{4}-\d{2}-\d{2})\.jsonl$/);
  if (match) {
    return new Date(match[1]);
  }
  return null;
}
```

### Safe Append with Warning on Failure

```typescript
async function safeAppend(path: string, content: string): Promise<void> {
  try {
    await appendFile(path, content + '\n');
  } catch (error) {
    console.warn('[telemetry:file] Write failed:', error.message);
  }
}
```

## Performance Considerations

### Write Latency

Target: < 5ms p99

- `appendFile` is essentially `open + write + close`
- For frequent writes, consider keeping file handle open
- Trade-off: open handle prevents rotation

**Recommendation**: Use `appendFile` for simplicity; optimize only if needed.

### Query Performance

Target: < 100ms for 10k events

- Stream reading avoids loading entire file into memory
- Date range filtering reduces files to scan
- Early termination when limit reached

### Disk Efficiency

Target: < 500 bytes/event average

Typical event JSON: ~300-400 bytes
- Minimal overhead with JSONL (newline delimiter only)
- Compression reduces by ~70-80% for text

## Error Scenarios

| Scenario | Handling |
|----------|----------|
| Disk full | Log warning, drop event |
| Permission denied | Log warning, drop event |
| Corrupted line in file | Skip line, continue parsing |
| Missing directory | Create on initialize |
| File locked | Unlikely (single-process); log warning if occurs |
