## Validation Rules

### Tool Name Format

```
<prefix>.<action_name>
```

1. **Exactly one dot**: Separates prefix from action
2. **Prefix**: snake_case, from STANDARD_PREFIXES or custom (with warning/error)
3. **Action**: snake_case only

### snake_case Pattern

```typescript
const SNAKE_CASE_PATTERN = /^[a-z][a-z0-9]*(_[a-z0-9]+)*$/;
```

Valid: `commit`, `run_tests`, `source_control`
Invalid: `Commit`, `run-tests`, `_hidden`, `123start`

| Scenario | Error Message |
