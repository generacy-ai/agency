# Quickstart: Tool Registry and Naming Convention

## Installation

The tool registry is part of the `@generacy-ai/agency` package:

```bash
pnpm add @generacy-ai/agency
```

## Basic Usage

### Registering Tools

```typescript
import { ToolRegistry, type AgencyTool } from '@generacy-ai/agency';

const registry = new ToolRegistry();

const myTool: AgencyTool = {
  name: 'source_control.commit',
  description: 'Commit staged changes',
  namespace: 'source_control',
  outputPattern: 'terse',
  inputSchema: {
    type: 'object',
    properties: {
      message: { type: 'string', description: 'Commit message' },
    },
    required: ['message'],
  },
  execute: async (params) => {
    // Implementation
    return { content: [{ type: 'text', text: 'Committed' }] };
  },
};

registry.register(myTool);
```

### Validating Tool Names

```typescript
// Permissive mode (default)
const result = registry.validateName('source_control.commit');
// { valid: true, errors: [], warnings: [] }

// Custom prefix generates warning
const customResult = registry.validateName('myplugin.action');
// { valid: true, errors: [], warnings: ['Using custom prefix: myplugin...'] }

// Strict mode rejects custom prefixes
const strictResult = registry.validateName('myplugin.action', { strict: true });
// { valid: false, errors: ['Custom prefix not allowed...'], warnings: [] }
```

### Querying Tools

```typescript
// Get all tools
const allTools = registry.getAll();

// Get by exact name
const tool = registry.get('source_control.commit');

// Get by prefix
const scTools = registry.getByPrefix('source_control');

// Get grouped catalog
const catalog = registry.getCatalog();
console.log(catalog.byPrefix['source_control']);
```

## Naming Convention

### Format

```
<prefix>.<action_name>
```

- **prefix**: Category identifier (snake_case)
- **action_name**: Specific operation (snake_case)

### Standard Prefixes

| Prefix | Use For | Examples |
|--------|---------|----------|
| `source_control` | Version control | `commit`, `push`, `diff` |
| `build` | Build operations | `install`, `compile`, `lint` |
| `run` | Runtime control | `start`, `stop`, `restart` |
| `test` | Testing | `unit`, `integration`, `e2e` |
| `humancy` | Human interaction | `ask_question`, `request_review` |
| `debug` | Debugging | `logs`, `breakpoint`, `trace` |
| `docs` | Documentation | `generate`, `search` |

### Custom Prefixes

Custom prefixes are allowed by default with a warning:

```typescript
// Valid but warns
registry.validateName('my_plugin.custom_action');
// warnings: ['Using custom prefix: my_plugin. Standard prefixes: source_control, build, ...']
```

For strict validation (e.g., official integrations):

```typescript
registry.validateName('my_plugin.custom_action', { strict: true });
// errors: ['Custom prefix not allowed in strict mode: my_plugin']
```

## Examples

### Plugin Development

```typescript
import { ToolRegistry, validateToolName, STANDARD_PREFIXES } from '@generacy-ai/agency';

function createPluginTool(action: string): AgencyTool {
  const name = `my_plugin.${action}`;

  // Validate before registration
  const validation = validateToolName(name);
  if (validation.warnings.length > 0) {
    console.log('Validation warnings:', validation.warnings);
  }

  return {
    name,
    // ... rest of tool definition
  };
}
```

### Catalog Generation

```typescript
const catalog = registry.getCatalog();

// JSON export
const json = JSON.stringify(catalog, null, 2);

// Group by prefix
for (const [prefix, tools] of Object.entries(catalog.byPrefix)) {
  console.log(`\n${prefix}:`);
  for (const tool of tools) {
    console.log(`  ${tool.name} - ${tool.description}`);
  }
}
```

## Troubleshooting

### "Tool name must contain exactly one dot separator"

Tool names must follow `prefix.action` format:

```typescript
// Wrong
'myaction'           // No dot
'my.nested.action'   // Multiple dots

// Correct
'build.compile'
```

### "Prefix must be snake_case"

Prefixes cannot contain hyphens or uppercase:

```typescript
// Wrong
'my-plugin.action'   // Hyphen
'MyPlugin.action'    // Uppercase

// Correct
'my_plugin.action'
```

### "Tool overwritten" Warning

Duplicate registration replaces the previous tool:

```typescript
registry.register({ name: 'build.compile', plugin: 'plugin-a', ... });
registry.register({ name: 'build.compile', plugin: 'plugin-b', ... });
// Warning: Tool 'build.compile' overwritten (was from plugin: plugin-a)
```

To avoid, check before registering:

```typescript
if (!registry.has('build.compile')) {
  registry.register(tool);
}
```
