# Implementation Plan: Fuse cockpit review findings presentation and approval prompt

**Feature**: Fuse cockpit review findings presentation and approval prompt into one turn to close the gate decay window
**Branch**: `388-found-during-cockpit-v1`
**Date**: 2026-07-08
**Spec**: [spec.md](./spec.md)
**Status**: Complete

## Summary

Restructure `packages/claude-plugin-cockpit/commands/review.md` so that findings analysis and the approval `AskUserQuestion` prompt are delivered in the **same response** (structural gate), replacing the current positional guarantee (steps 3/4 → step 5 across a turn boundary). Fuse current steps 3 (implementation-review analysis), 4 (artifact-review analysis), and 5 (approval prompt) into a single fused step (new step 3) whose body branches internally on `--gate` and terminates in one shared `AskUserQuestion` invocation. Retain the Terminal Outcome Check block as a secondary backstop covering post-decision execution (renumbered steps 5–7). Update all `## Examples` that touch the fused step to render analysis-and-prompt in the same response block.

The change is a **documentation/playbook edit** — no runtime code, no schema, no CLI wiring. The "runtime" is the model executing the playbook; the "contract" is the greppable rule sentence plus the fused-step shape.
