## Workflow

1. Read and parse tasks.md
2. Validate dependencies (fail on circular)
3. Determine grouping strategy
4. Generate issue plans
5. Check for duplicates (search existing tickets)
6. If not dry_run:
   - Create tickets in dependency order
   - Update tasks.md with ticket links
7. Return summary of created/planned tickets
