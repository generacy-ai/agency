# Quickstart: D5 tasks_to_issues Tool

## Overview

The `spec_kit.tasks_to_issues` tool converts tasks from a tasks.md file into GitHub issues. It supports multiple grouping strategies and handles dependencies between tasks.

## Prerequisites

- GitHub CLI (`gh`) installed and authenticated
- tasks.md file in the feature directory
- Valid feature branch (e.g., `164-feature-name`)

## Basic Usage

### Preview Issues (Dry Run)

```json
{
  "tool": "spec_kit.tasks_to_issues",
  "params": {
    "dry_run": true
  }
}
```

This shows what issues would be created without actually creating them.

### Create Issues

```json
{
  "tool": "spec_kit.tasks_to_issues",
  "params": {
    "dry_run": false
  }
}
```

Creates GitHub issues and updates tasks.md with issue links.

## Grouping Strategies

### Per-Task (Default)
One issue per task - finest granularity.

```json
{
  "grouping": "per-task"
}
```

### Per-Story
Groups tasks by user story (US1, US2, etc.).

```json
{
  "grouping": "per-story"
}
```

### Per-Phase
Groups tasks by phase - coarsest granularity.

```json
{
  "grouping": "per-phase"
}
```

### Auto-Detection
If no grouping is specified, the tool checks for `epic-grouping:*` labels on the parent epic.

## Task Formats

### Individual Tasks (T###)

```markdown
## Phase 1: Setup

- [ ] T001 [US1] Initialize project structure (deps: none)
- [ ] T002 [US1] Setup database schema (deps: T001)
- [ ] T003 [P] [US2] Implement API endpoints

## Phase 2: Core

- [ ] T004 [US2] Add authentication middleware (deps: T002)
```

Markers:
- `[#N]` - Existing issue link (skipped)
- `[P]` - Parallelizable task
- `[US#]` - User story reference
- `(deps: T001, T002)` - Dependencies

### Task Groups (TG-XXX)

```markdown
## Phase 1: Setup

### TG-001 [US1] Initialize Project

**Scope**: S
**Files**:
- `src/index.ts`
- `package.json`
**Tests**: Unit tests for initialization

- [ ] Create project structure
- [ ] Setup TypeScript config
- [ ] Add initial dependencies
```

## Common Options

| Parameter | Type | Description |
|-----------|------|-------------|
| `grouping` | string | `per-task`, `per-story`, `per-phase` |
| `dry_run` | boolean | Preview without creating |
| `epic_number` | integer | Parent epic (auto-detected) |
| `feature_dir` | string | Feature directory path |
| `cwd` | string | Working directory |

## Troubleshooting

### "GitHub CLI not installed"
```bash
# Install gh CLI
brew install gh  # macOS
apt install gh   # Ubuntu
```

### "Not authenticated"
```bash
gh auth login
```

### "Circular dependency detected"
Check your tasks.md for dependency cycles:
- T001 depends on T002
- T002 depends on T001 (circular!)

Fix by removing or reordering dependencies.

### "Review gate blocked"
For epic issues, add the `completed:tasks-review` label to proceed.

### "Task already has issue"
Tasks with `[#N]` markers are skipped. Remove the marker to recreate.
